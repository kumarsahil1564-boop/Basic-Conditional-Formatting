# Task 29 – Basic Conditional Formatting

## Objective
Improve report readability by automatically highlighting high and low values in a retail sales workbook.

## Tool
- Microsoft Excel

## Files
- `Task_29_Basic_Conditional_Formatting.xlsx` – formatted workbook with Retail Sales, Rules List, and Summary sheets.
- `retail_sales_data.csv` – source dataset.
- `rules_list.md` – documented conditional formatting rules.

## Key Features
- Revenue 3-color scale
- High-profit highlighting
- High-units highlighting
- Low and high profit-margin highlighting
- Excel table formatting
- Frozen header row
- Summary calculations

## Outcome
Conditional formatting makes important sales and profitability patterns easier to identify without manually coloring cells.
